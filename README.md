# 爬蟲專案開發流程

1. 定義目標
   - 確認要爬取的網站、資料項目、格式。

2. 環境準備
   - 建立虛擬環境、安裝 requests、BeautifulSoup、pandas 等套件。

3. 測試抓取
   - 先用瀏覽器觀察網頁結構。
   - 撰寫簡單 request 抓取 HTML。

4. 解析資料
   - 用 BeautifulSoup 或 lxml 解析需要的欄位。
   - 先抓一筆資料測試正確性。

5. 儲存結果
   - 將資料寫成 CSV、JSON 或資料庫。

6. 加入例外處理
   - 處理 HTTP 錯誤、重試、延遲、反爬機制。

7. 測試與優化
   - 確認資料完整、效能可接受。
   - 如有需要，分批爬取或加上日誌。

8. 完成專案
   - 撰寫簡單說明、使用方式。
   - 備份程式碼與資料。
